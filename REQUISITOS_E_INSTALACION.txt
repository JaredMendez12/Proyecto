PROYECTO PARCIAL 1 - Requisitos, Instalacion y Ejecucion
===================================================================

1. REQUISITOS
-------------
- Sistema operativo: Windows 10/11 (el proyecto usa mpiexec y os.startfile,
  especificos de Windows).
- Python 3.10 o superior.
- Microsoft MPI (MS-MPI) instalado en el sistema. Es obligatorio para que
  mpi4py y el comando "mpiexec" funcionen en Windows.
  Descarga: https://www.microsoft.com/en-us/download/details.aspx?id=105289
  Instala AMBOS paquetes del instalador: msmpisetup.exe y msmpisdk.msi.
- pip (incluido con Python).

Paquetes de Python necesarios:
  pandas
  numpy
  matplotlib
  mpi4py
  streamlit      (solo si se usa la interfaz web app.py)
  sv_ttk         (solo si se usa la interfaz de escritorio gui.py)

(tkinter viene incluido con la instalacion estandar de Python en Windows,
no requiere instalacion aparte).

Dataset:
- Se necesita el archivo "data/raw/dataset.csv" (Steam Reviews) antes de
  generar la muestra con main.py. Este archivo NO se genera solo, debe
  colocarse manualmente en esa ruta.
- Descarga: https://www.kaggle.com/datasets/andrewmvd/steam-reviews
  Descarga el dataset desde Kaggle, descomprimelo y coloca el CSV resultante
  en "data/raw/dataset.csv" (crea las carpetas data/raw si no existen).


2. INSTALACION
---------------
1. (Opcional pero recomendado) Crea y activa un entorno virtual:
     python -m venv venv
     venv\Scripts\activate

2. Instala las dependencias de Python:
     pip install pandas numpy matplotlib mpi4py streamlit sv_ttk

3. Instala Microsoft MPI (MS-MPI) usando el instalador oficial de Microsoft
   (ver enlace en la seccion de Requisitos). Reinicia la terminal despues
   de instalarlo para que el comando "mpiexec" quede disponible en el PATH.

4. Verifica que mpiexec este disponible:
     mpiexec -help

5. Descarga el dataset desde https://www.kaggle.com/datasets/andrewmvd/steam-reviews
   y coloca el CSV resultante en:
     data/raw/dataset.csv


3. PASOS PARA EJECUTAR
------------------------

Paso previo (obligatorio): generar la muestra del dataset
     python main.py

Luego elige UNA de las siguientes formas de ejecutar el proyecto:

OPCION A: Version secuencial (linea base, un solo hilo)
     python src\secuencial.py

OPCION B: Version paralela manual con MPI (ejemplo con 4 procesos)
     mpiexec -n 4 python src\paralelo.py

OPCION C: Benchmark completo (RECOMENDADO)
Corre automaticamente con 1, 2, 4 y 8 procesos, calcula aceleracion,
eficiencia, fraccion secuencial (Ley de Amdahl) y genera las graficas:
     python src\benchmark.py
Los resultados quedan en consola y las graficas se guardan en
"resultados/graficas/".

OPCION D: Interfaz de escritorio (Tkinter, gui.py)
     python gui.py
Abre una ventana con botones para correr cada paso (generar muestra,
secuencial, paralelo, benchmark), ver las graficas de forma interactiva
y revisar la tabla de resultados (tiempos.csv).

OPCION E: Interfaz web (Streamlit, app.py)
     python -m streamlit run app.py
Abre un panel de control en el navegador con los mismos pasos que la
version de escritorio, mostrando logs en vivo y graficas.

Nota: tanto gui.py como app.py solo ejecutan por detras los mismos
comandos de las opciones A, B y C; son paneles de control opcionales,
no reemplazan la ejecucion por terminal.
